## O Projektu
Projekat je Seminarski rad iz predmeta Veb Dizajn i predstavlja kancelarijski namestaj. Projekat sadrzi vise razlicitih stranica:
- Pocetna Stranica
- O Nama
- Galerija
- Proizvodi
- Kontakt Stranica


## Pocetna Stranica
Sadrzi informacije poput korisnickog feedback-a, opcija za nalog i takodje je responzivna.
